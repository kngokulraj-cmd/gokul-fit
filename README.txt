Gokul Fit V3

New:
- 2–3 second looping visual demo for every main exercise
- Individual set completion buttons
- 60 / 90 / 120 second rest timer
- Water tracker
- Night-shift-specific daily sleep guidance
- Meal calorie + protein log
- Meal-prep checklist
- Weight graph and milestone progress
- Automatic progress guidance
- Strength tracker
- Workout history
- Export/import backup

Install on iPhone:
1. Upload all files to an HTTPS static host such as GitHub Pages.
2. Open the site in Safari.
3. Share > Add to Home Screen.

All tracking data stays locally in Safari unless you export a backup.
