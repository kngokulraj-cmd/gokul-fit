- Mission 75 dashboard
- weekly training calendar
- bigger exercise demo cards
- full-screen guided workout mode
- one-tap set completion

- daily completion ring and streak
- milestone progress

- night-shift strategy
- progress chart
- profile / backup area

UPDATE EXISTING GITHUB APP:
1. Open the existing gokul-fit repository.
2. Replace index.html, manifest.json, sw.js and icon.svg.
3. Commit.
4. Wait for GitHub Pages to redeploy.
5. Open the website in Safari and refresh once.
6. If Home Screen still displays an old cached version, remove the Gokul Fit Home Screen icon and add it again after refreshing Safari.
