UPDATE GITHUB PAGES
1. Extract this ZIP.
2. In the existing gokul-fit repository, delete or overwrite index.html, manifest.json, sw.js, icon.svg.
3. Upload these four new files.
4. Commit changes.
5. Wait 1–3 minutes.
6. Open the live GitHub Pages URL in Safari and refresh once.
7. If the Home Screen version remains old, remove that Home Screen icon and add it again from the refreshed Safari page.
