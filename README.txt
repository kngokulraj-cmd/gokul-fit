HOW TO UPDATE YOUR EXISTING GITHUB PAGES APP

1. Download and extract Gokul_Fit_Premium_V6.zip.
2. Open your existing GitHub `gokul-fit` repository.
3. Delete or overwrite the existing:
   - index.html
   - manifest.json
   - sw.js
   - icon.svg
4. Upload the four new files from this package.
5. Commit the changes.
6. Wait about 1–3 minutes for GitHub Pages to redeploy.
7. Open your GitHub Pages URL in Safari and refresh it once.
8. Close the Home Screen app and reopen it.
9. If the old version still appears, remove the Gokul Fit Home Screen icon, open the refreshed Safari site, and choose Share > Add to Home Screen again.

The new service worker uses network-first updates, so future versions should refresh more reliably.
